Política de Privacidade

Última atualização: 21 de junho de 2026

Aviso: este documento foi redigido para refletir, de forma direta, como os dados coletados neste site são usados. Ele não substitui orientação jurídica especializada. Antes de publicar definitivamente, recomenda-se revisão por um advogado especializado em proteção de dados (LGPD), especialmente por se tratar de coleta de dados de saúde.

1. Quem é responsável pelos seus dados

Paola Fernanda Ribeiro, nutricionista inscrita no CRN-3 sob o nº 76261, é a controladora dos dados pessoais coletados através deste site (paolaribeironutricionista.com.br). Para qualquer questão sobre seus dados, o contato é paola@paolaribeironutricionista.com.br.

2. Quais dados são coletados

Este site coleta dados em dois momentos:

  • Formulário de contato rápido: nome, e-mail, WhatsApp, assunto e mensagem.
  • Formulário de atendimento (anamnese nutricional): dados de identificação (nome, data de nascimento, sexo, cidade, contato) e dados de saúde — peso, altura, condições clínicas (como diabetes, hipertensão, SOP), uso de medicamentos, alergias alimentares, exames, rotina, hábitos alimentares e histórico de acompanhamento nutricional.

Os dados de saúde são classificados como dados pessoais sensíveis pela Lei Geral de Proteção de Dados (Lei nº 13.709/2018, Art. 5º, XIII), e por isso recebem tratamento mais cuidadoso, descrito abaixo.

3. Para que os dados são usados

  • Viabilizar o contato inicial e o agendamento de consultas;
  • Realizar a avaliação nutricional e elaborar o plano alimentar personalizado;
  • Dar continuidade ao acompanhamento entre consultas;
  • Cumprir obrigações profissionais de registro do atendimento, quando aplicável.

Os dados não são usados para envio de marketing por terceiros, nem vendidos ou compartilhados com empresas de publicidade.

4. Base legal para o tratamento

O tratamento dos dados de identificação e contato se baseia no consentimento do titular (Art. 7º, IX da LGPD), fornecido ao preencher e enviar os formulários. O tratamento dos dados de saúde, por serem dados sensíveis, exige consentimento específico e destacado (Art. 11, II, "a" da LGPD) — por isso o envio do formulário de atendimento depende da confirmação explícita de um campo de aceite antes do envio.

5. Como os dados são armazenados e compartilhados

Os formulários deste site são processados pela plataforma Web3Forms, um serviço terceirizado de envio de formulários por e-mail, que atua como operador de dados nos termos da LGPD (Art. 5º, VII). As respostas chegam por e-mail diretamente à caixa de entrada de Paola Ribeiro. Não há banco de dados próprio do site nem armazenamento em servidor além do necessário para o envio do e-mail.

Durante o preenchimento do formulário de atendimento, os dados ficam temporariamente salvos no navegador do próprio usuário (sessionStorage), apenas para evitar perda de preenchimento — esses dados são apagados automaticamente ao fechar a aba do navegador e não são acessados por terceiros.

6. Por quanto tempo os dados são mantidos

Os dados enviados são mantidos pelo tempo necessário para a finalidade do atendimento nutricional e cumprimento de obrigações profissionais e legais aplicáveis à área da saúde. Você pode solicitar a exclusão dos seus dados a qualquer momento, conforme descrito no item 7.

7. Seus direitos como titular dos dados

Conforme o Art. 18 da LGPD, você tem direito a:

  • Confirmar a existência de tratamento dos seus dados;
  • Acessar os dados que foram coletados;
  • Corrigir dados incompletos, inexatos ou desatualizados;
  • Solicitar a anonimização, bloqueio ou eliminação de dados desnecessários;
  • Solicitar a portabilidade dos dados a outro fornecedor;
  • Eliminar os dados tratados com consentimento;
  • Revogar o consentimento, a qualquer momento.
Para exercer qualquer um desses direitos, envie um e-mail para paola@paolaribeironutricionista.com.br com o assunto "Dados pessoais — LGPD". A solicitação será respondida dentro de um prazo razoável.

8. Segurança

O site é transmitido via conexão criptografada (HTTPS). O envio de formulários ocorre por canal seguro até o provedor Web3Forms. Nenhum sistema é 100% livre de risco, mas medidas razoáveis são adotadas para proteger os dados contra acesso não autorizado.

9. Cookies e rastreamento

Este site não utiliza cookies de rastreamento, pixels de redes sociais ou ferramentas de analytics de terceiros no momento desta publicação.

10. Alterações desta política

Esta política pode ser atualizada para refletir mudanças no site ou na legislação. A data da última atualização está sempre indicada no topo desta página.
